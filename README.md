# Privacy Policy for English Mastery

**Effective Date:** October 19, 2026

English Mastery ("the App") is built as a 100% offline-first educational application.

## 1. Zero Personal Data Collection
The App does not request Internet access (`android.permission.INTERNET` is absent) and does not collect, transmit, track, or share any personal information, usage analytics, device identifiers, or location data with any external server or third party.

## 2. On-Device Local Storage
All learning records—including completed lessons, quiz accuracy, flashcard spaced-repetition schedules, earned gems/certificates, theme preferences, and any optional learner name entered by the user—are stored exclusively on your device using local Android storage (SQLite and SharedPreferences).

## 3. User Data Control, Backup & Deletion
- You can reset and permanently delete all saved learning progress at any time inside the App via **Settings (Personalize) → Reset Learning Progress**, or by uninstalling the App.
- When you use **Export Backup**, **Share Certificate**, or **Share Cheat-Sheet**, files are saved or shared only where you explicitly choose using Android's system file picker or share sheet.

## 4. Permissions Used
- `POST_NOTIFICATIONS` (Optional): Used solely to schedule local on-device daily study streak reminders when enabled by the user in Settings.
